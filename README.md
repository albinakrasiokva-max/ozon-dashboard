# BrandOS — дашборд селлера WB + Ozon

Этап 1: интерфейс на демо-данных. Откройте `index.html` в браузере — сервер не нужен.

- Все демо-данные лежат в одном объекте `DATA` в начале `<script>` — его потом заменят реальные данные.
- Задачи, сделки, документы и статусы решений сохраняются в `localStorage` браузера.
- Блоки, к которым ещё не подключён источник, помечены «демо».

Разделы: Главная, Центр решений (встроенные правила), Аналитика, Финансы, Продажи, Маркетплейсы,
Реклама, CRM (канбан), Склад, Поставки, Налоги, Документы, Интеграции, Задачи (канбан), ИИ-ассистент.

Следующие этапы: сервер на Node.js и реальные API → документы и ИИ → Центр решений на Claude → деплой.
